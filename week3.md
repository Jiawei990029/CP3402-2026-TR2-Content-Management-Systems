# Week 3 – WordPress CMS

## Goal

The goal of this practical was to learn how to build and manage a website using WordPress. I explored the WordPress dashboard, created website content, organised navigation, customised the site appearance, and published the website online.

---

## Practical Work

During this practical I used WordPress to develop my startup website **StudyFlow AI**.

Website:
http://studyflow-ai.42web.io/

In this practical I:

- Installed and configured a WordPress website.
- Created multiple pages for the website.
- Organised the navigation menu.
- Customised the website using a WordPress theme.
- Edited page layouts and content.
- Used WordPress plugins to improve website functionality.
- Published the completed website online for public access.

The website introduces StudyFlow AI, a platform designed to help students improve their learning efficiency through AI-assisted study tools and a modern user interface. ## Learning

This practical helped me understand the advantages of using a Content Management System compared with creating static HTML pages. WordPress allows website content, themes and plugins to be managed efficiently through the administrator dashboard without editing every page manually.

I also learned how themes control the appearance of a website while plugins extend its functionality, making WordPress suitable for building professional websites quickly.

---

## Reflection

Completing this practical improved my confidence in using WordPress. I became familiar with page management, menus, themes and plugins, and learned how to publish a functional website online. These skills will be useful for developing the custom WordPress theme required in the group project later in this subject.
