# Week 7 – PHP Programming

## Goal

The goal of this practical was to improve my understanding of PHP programming and learn how PHP is used in WordPress theme development. I also applied PHP concepts while contributing to our group project, StudySphere.

---

## Practical Work

During this practical, I studied the basic features of PHP and explored how PHP generates dynamic web pages in WordPress.

I completed a PHP practice program that demonstrated:

- Using `echo` to output HTML content.
- Using `if` and `else` statements for decision making.
- Using `for`, `while`, and `foreach` loops.
- Creating reusable functions with parameters.
- Using `include` to load a shared header and footer.

After learning these PHP features, I applied the knowledge while working on our StudySphere project. Since WordPress themes are built using PHP template files, I became more familiar with files such as `index.php`, `header.php`, `footer.php`, and `functions.php`.

I also continued contributing to the group project through GitHub by updating code and collaborating with other team members.

---

## Learning

This practical helped me understand that PHP is the core programming language behind WordPress. Unlike HTML, PHP can generate dynamic content and interact with WordPress functions to display posts, pages, menus, and other website information.

I also learned that organising common page elements with `include` improves code reuse and makes websites easier to maintain.

Working with PHP gave me more confidence when reading and modifying WordPress theme files.

---

## Reflection

Learning PHP was an important step before developing our custom WordPress theme. I now have a better understanding of how WordPress templates work and how PHP connects different parts of a website.

By applying PHP concepts in the StudySphere project, I gained practical experience in both programming and collaborative software development. This practical strengthened my coding skills and prepared me for more advanced WordPress theme development in the following weeks.
