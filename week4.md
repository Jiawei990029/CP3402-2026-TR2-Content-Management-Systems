# Week 4 – Development and Deployment Workflows

## Goal

The goal of this practical was to understand a typical web development and deployment workflow. I learned how to develop a website, manage project files with GitHub, and deploy the website to an online hosting service.

---

## Practical Work

During this practical I worked on the deployment workflow for my WordPress website.

Website:
http://studyflow-ai.42web.io/

In this practical I:

- Organised my project files using GitHub.
- Used GitHub to keep track of website changes.
- Deployed the website to InfinityFree hosting.
- Verified that the website was publicly accessible.
- Tested the website after deployment to ensure pages and navigation worked correctly.

This workflow helped me understand how developers move a website from development to a live production environment.

---

## Learning

I learned that a development workflow is important for keeping projects organised and reducing errors. Using GitHub allows developers to track changes and collaborate with others, while online hosting services make websites available to users anywhere.

I also learned that testing after deployment is necessary to ensure that links, pages and website functions work correctly.

---

## Reflection

This practical gave me a better understanding of professional web development workflows. I now understand how version control, deployment and testing work together to produce a reliable website. These skills will be valuable for the group WordPress project later in this subject.
