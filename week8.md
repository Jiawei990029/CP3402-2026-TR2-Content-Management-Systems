# Week 8 – Learning Experiment & Presentation Rehearsal

## Goal

The goal of this practical was to investigate whether AI-assisted development could improve our team's efficiency while developing the StudySphere WordPress project. We also completed a rehearsal of our final presentation to evaluate our communication and project demonstration.

---

## Learning Experiment

### Hypothesis

Using AI development tools together with GitHub collaboration can improve development efficiency while maintaining code quality.

---

### Experiment

To test this hypothesis, our team compared our development process before and after introducing AI tools such as Cursor during the StudySphere project.

We compared:

- Time required to create basic project structure.
- Speed of writing HTML, CSS and PHP code.
- Time spent debugging generated code.
- Team collaboration through GitHub.

After generating code with AI, every team member reviewed, modified and tested the code before committing it to GitHub.

---

### Result

The experiment showed that AI significantly reduced the time required to create the initial project structure and repetitive code.

AI was particularly helpful for:

- Generating template code.
- Creating page layouts.
- Writing basic HTML, CSS and PHP.
- Explaining unfamiliar WordPress functions.

However, AI-generated code was not always correct and sometimes required manual debugging and optimisation before it could be used in our project.

Therefore, our hypothesis was supported.

---

## Presentation Rehearsal

Our team completed a rehearsal of the final project presentation.

During the rehearsal we:

- Introduced the StudySphere project.
- Demonstrated our collaborative GitHub workflow.
- Explained our WordPress custom theme development.
- Presented our AI-assisted development experiment.
- Identified areas where our presentation could be improved.

After the rehearsal, we discussed improvements including:

- Speaking more clearly.
- Improving transitions between presenters.
- Demonstrating the website more smoothly.
- Better explaining our development workflow.

---

## Learning

This experiment showed that AI is a valuable assistant during software development but cannot replace human judgement.

Although AI increased our productivity, code review, testing and teamwork remained essential to ensure software quality.

I also learned that GitHub collaboration became more effective because team members could spend less time writing repetitive code and more time improving the overall project.

---

## Reflection

Week 8 helped me understand how AI can be integrated into modern software development workflows. Rather than replacing developers, AI serves as a tool that supports faster development and learning.

The presentation rehearsal also gave our team confidence before the final assessment. We discovered several areas for improvement and refined both our presentation and our project before submission.

Overall, this practical strengthened both my technical skills and my experience working collaboratively on the StudySphere project.
