# Week 5 – WordPress Child Themes

## Goal

The goal of this practical was to understand how WordPress themes can be customised safely by using child themes. I also learned how themes control the appearance and layout of a website.

---

## Practical Work

During this practical I explored how WordPress themes are structured and how they can be customised without changing the original theme files.

In this practical I:

- Explored the structure of WordPress themes.
- Learned the purpose of child themes.
- Modified website appearance using theme settings.
- Changed page layouts and styling with CSS.
- Tested different theme customisation options.
- Applied design improvements to make the website more modern and user-friendly.

These activities helped prepare me for developing custom WordPress themes in later assessments.

---

## Learning

I learned that a child theme allows developers to customise a WordPress website while keeping the parent theme unchanged. This makes future updates much safer because custom changes are not lost when the parent theme is updated.

I also learned how CSS and theme templates work together to control the appearance of a WordPress website.

---

## Reflection

This practical improved my understanding of WordPress theme development. I now understand the relationship between parent themes, child themes and custom styling. These skills will help me develop more professional and maintainable WordPress websites in future projects.
