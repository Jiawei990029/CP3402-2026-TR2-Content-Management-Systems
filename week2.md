# Week 2 – Joomla CMS

## Goal

The goal of this practical was to learn how to use Joomla as a Content Management System (CMS). I explored the Joomla administrator interface, managed website content, and published a working website online.

## What I Did

- Installed and configured Joomla.
- Created and organised website pages.
- Edited content using the Joomla administrator panel.
- Applied a template to improve the website's appearance.
- Published the website successfully.

## Reflection

This practical helped me understand how Joomla manages website content separately from design. I became familiar with the administrator interface, page management, menus, and templates. Deploying the website online also improved my understanding of web hosting and CMS deployment.
