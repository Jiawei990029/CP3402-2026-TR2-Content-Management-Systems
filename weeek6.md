# Week 6 – Group Setup

## Goal

The goal of this practical was to establish the project team, organise collaboration tools, and prepare a development workflow for the group project. We planned how the team would communicate, manage tasks, and develop our custom WordPress website.

---

## Practical Work

During this practical, our team began setting up the group project for **StudySphere**, a WordPress website designed to provide students with an organised and user-friendly learning platform.

Our team completed the following setup tasks:

- Joined the shared GitHub repository.
- Discussed the project requirements and client expectations.
- Assigned roles and responsibilities to each team member.
- Planned the website structure and required pages.
- Agreed on using GitHub for version control and collaborative development.
- Discussed the project workflow and development timeline.
- Held our first stand-up meeting to review responsibilities and upcoming tasks.

During the planning stage, I mainly focused on the technical development of the project and prepared to work on the WordPress theme and coding tasks in the following weeks.

---

## Learning

This practical helped me understand the importance of teamwork in software development. Using GitHub allows multiple developers to work on the same project while keeping changes organised through version control.

I also learned that project planning at the beginning of development reduces confusion later. Clearly assigning responsibilities and maintaining regular communication helps the team complete work more efficiently.

The stand-up meeting was useful because every team member shared:

- What had been completed.
- Any problems encountered.
- The work planned for the following week.

This improved communication and ensured everyone understood the project progress.

---

## Reflection

Completing the group setup gave me a better understanding of how professional software development teams organise projects before coding begins. Instead of immediately developing the website, we first established communication methods, task management, and development workflows.

This preparation made our later development of the StudySphere WordPress theme much more organised and efficient. I also gained more experience using GitHub as a collaborative development tool and working as part of a software development team.
